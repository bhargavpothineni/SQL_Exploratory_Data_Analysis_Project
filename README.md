# SQL_Exploratory_Data_Analysis_Project

This repo contains a collection of SQL scripts demonstrating various **analytical techniques**, such as changes over time, cumulative, performance, data segmentation, part-to-whole analysis.

## Project Overview
This Project Involves **Reports for both Customers and Products** derived from **gold Tables** from previous **Data Warehouse Project** (`gold.fact_sales`, `gold.dim_products`, `gold.dim_customers`).

## Project Involves

1. **Creating Views**
2. **Creating CTE's**
3. **Analysing Trends**
4. **Calculating Valuable KPI's**  
   **For Customer Report:**        
   - recency (months since last order)
   - average order value
   - average monthly spend
   
   **For Product Report:**
   - recency (months since last sale)
   - average order revenue (AOR)
   - average monthly revenue

5. **Customer Segmentation**
6. **Product Segmentation**
7. **Aggregations**
   - total orders
   - total sales
   - total quantity sold
   - total customers (unique)
   - lifespan (in months)
   - total quantity purchased
   - total products
